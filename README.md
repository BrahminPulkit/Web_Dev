# Web Development Practice

A collection of lecture-based web-development exercises covering HTML, CSS,
JavaScript and Node.js examples. Directories are organized by lesson rather than
as one deployable application.

## Explore

- Open a lesson's HTML file to inspect its layout and scripts.
- For Node.js examples, use the lesson directory containing `package.json`,
  install dependencies locally and review its scripts before running it.
- `Lecture10/MediumClone/` contains a static layout exercise.

Install dependencies locally when working on the examples. The .gitignore
prevents newly generated dependencies from being added; existing tracked
dependencies still need a separate cleanup. This is a
practice repository; see the [profile](https://github.com/BrahminPulkit) for
complete application and analytics projects.
